# Can AI Pay for Itself?

An experiment: can AI coding agents (Devin, mostly on free models, coordinated in Orca) earn
US$200 in one month (deadline 2026-12-21) with near-zero startup cost, enough to pay for the
subscription that runs them?

- `AGENTS.md`: operating manual, rules and folder map
- `ops/STATE.md`: live status and money tracker
- `agents/<name>/log.json`: each agent's structured work log (JSON)
- `agents/<name>/transcript.json`: each agent's full conversation (ATIF JSON, redacted)
- `ops/specs/`: the exact task each agent was given

Prospects' contact details and previews built for real businesses are kept out of this repo,
and transcripts are redacted (emails, phone numbers, tokens) before they are published.
