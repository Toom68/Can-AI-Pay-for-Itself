# Brand — decisions summary

**Recommended name: Brissie Sites** (`brissiesites` everywhere).
Alternates: **Jacaranda Web** (`jacarandaweb`), **Bunya Web** (`bunyaweb`).

- `names.md` — 8 candidates checked 2026-11-21: GitHub org (all free), `.com` (all free),
  `.com.au` (bilbyweb + banksiaweb taken — both rejected, and both had conflicting
  business names on ABN Lookup). Stormbird too crowded, Kooka sits near the KOOKAI
  fashion brand. Brissie Sites wins on clarity: the name explains the offer to a
  Brisbane business owner before the email is even opened.
- `kit.md` — tagline ("We build it first. You only pay if you love it."), tone
  (friendly/plain/honest), palette (river teal + mango on sandstone paper), typography
  (system stack, optional free Sora/Space Grotesk upgrade), logo usage.
- `logo.svg` — sun-over-river roundel + wordmark.
- `studio-site/` — one-page site (hero, preview-first explainer, what's included,
  A$249 pricing + A$15/mo care plan, sample portfolio linking `/_samples/…`, FAQ,
  mailto contact). Brand name + email each appear in clearly marked single spots;
  verified at true 375px and 1280px (screens in `_screens/`).
- `sales/` — Spam-Act-compliant cold emails (3 × <120 words), one-follow-up policy,
  reply playbook with handover steps, quote/invoice templates with the ATO
  "Statement by a supplier" wording, one-page plain-English agreement
  (parent co-signs), and a 60-second walk-in script.
