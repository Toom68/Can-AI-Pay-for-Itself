POCKET CHIP KIT — chiptune sample & MIDI pack
============================================

90+ original 8-bit / NES-style sounds for games, music and jams.
Everything is synthesized (square, pulse, triangle, triangle-sub and LFSR
noise voices) and rendered to clean 44.1 kHz / 16-bit mono WAV.

CONTENTS
--------
  audio/drums/   kicks, snares, hats, clap, toms, rim, noise hits, blips
  audio/bass/    triangle / pulse / square / sub basses, one file per note
                 (C1 E1 G1 A1 B1 F1 — pitch them in your sampler for the rest)
  audio/lead/    square / pulse / triangle leads, C4–E5
  audio/fx/      coin, jump, laser, power-up, damage, risers, sweeps, arps,
                 select/confirm, zap, tick
  audio/loops/   drum loops (120 & 140 BPM, 3 patterns each), bassline loops,
                 arpeggio loops — all seamless 2-bar loops
  midi/          4 drum patterns (GM map), 4 basslines, 4 melodies
  preview.html   open in any browser to audition the whole kit

USAGE
-----
Drag the WAVs into any DAW, tracker or engine (FL Studio, Ableton, Renoise,
FamiStudio, DefleMask, Godot, Unity, GameMaker...). The MIDI files import
anywhere and are written at 480 PPQ in GM note layout (drum patterns use
kick=36, snare=38, hats=42/46).
